# 隐私说明

- 歌词匹配只在本地发起:应用读取系统媒体会话的**曲目元数据**
  (标题/艺术家/专辑/时长),仅用于向歌词来源发起搜索查询。
- 所有数据保存在本机 `%LOCALAPPDATA%\LyricsX`
  (设置、歌词缓存、手动关联、日志)。
- Spotify 的 refresh token 保存于 **Windows 凭据管理器**
  (`LyricsX/SpotifyRefreshToken`),不落文件盘;断开连接即删除。
- **无任何遥测**。应用不联网上报使用数据。
- 日志经过脱敏:不包含歌名、艺术家、歌词内容、浏览器 URL、
  账户标识、凭据或绝对用户路径。
- 卸载时默认保留上述本地数据;只有你明确确认(或静默卸载传
  `/DELETEUSERDATA=1`)才会删除。
