# LyricsX Windows — UI 冒烟验收清单

运行环境:Windows 11 x64 与 ARM64(计划 04)。逐项勾选,任何失败记录复现步骤。

## 键盘可达性
- [ ] 任务栏歌词窗口不参与 Tab 焦点循环(NOACTIVATE)
- [ ] 右键菜单可由键盘 Menu 键 / Shift+F10 唤起
- [ ] 偏好设置窗口全部控件可 Tab 到达,Enter 触发 Apply,Esc 取消
- [ ] 手动搜索窗口:Tab 顺序 歌曲名→艺术家→搜索→结果→按钮

## 显示缩放
- [ ] 100%:歌词条位于任务栏空区,高度贴合
- [ ] 125% / 150%:DIP 定位正确,文字不模糊
- [ ] 200%:同上,无裁剪

## 主题
- [ ] 浅色主题:文字可读,阴影对比正确
- [ ] 深色主题:同上
- [ ] 高对比度主题:文字可读

## 动效
- [ ] 跟随 Windows"动画效果"设置:关闭时歌词走省略号截断
- [ ] 开启时超长歌词跑马灯滚动(800ms 起始停顿)

## 本地化
- [ ] zh-CN:全部菜单/偏好文案与规范一致(偏好设置… 等)
- [ ] en-US:回退显示英文

## 屏幕阅读器
- [ ] 讲述人朗读当前歌词全文(AutomationProperties.Name)
- [ ] 菜单项均有可读名称

## 菜单行为
- [ ] 任务栏歌词左键 → 紧凑菜单
- [ ] 右键 → 完整菜单
- [ ] 托盘左键/右键 → 完整菜单(光标处)

## 偏好设置
- [ ] 宽度越界(80–360 外)Apply 禁用并显示内联错误
- [ ] 偏移 ±30s 夹取
- [ ] 至少一个歌词源启用约束生效
- [ ] 快捷键冲突提示;取消恢复原注册

## 手动搜索
- [ ] 歌曲名/艺术家预填;新搜索取消旧查询
- [ ] 仅本次使用 / 始终用于这首歌 / 取消关联 行为正确

## 任务栏覆盖
- [ ] 点击歌词不抢焦点
- [ ] Alt+Tab 不出现歌词窗口
- [ ] 全屏应用自动隐藏
- [ ] Explorer 重启后重定位不崩溃
