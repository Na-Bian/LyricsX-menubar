# 故障排除

## 没有显示"正在播放"

1. 确认播放器正在播放;
2. 播放器需支持系统媒体控件(GSMTC):在播放器设置里启用"系统媒体传输控制/
   SMTC/媒体信息共享";
3. 播放器会话列表查看页在后续版本;重启 LyricsX 后再试;
4. 重启播放器后再试。

## 找不到歌词 / 一直"正在搜索歌词…"

1. 手动搜索窗口在后续版本;当前可将 LRC 文件放入缓存目录(高级用法);
2. 来源启用与排序的完整 UI 在后续版本;当前版本默认启用全部五个
   内置来源;
3. 部分曲目在所有来源均无同步歌词,属正常;
4. 网络受限时在线来源不可用,本地歌词文件不受影响。

## 歌词来源不对 / 优先级不生效

偏好设置 → 来源拖动排序。顺序在匹配质量相同时作为决胜依据。
禁用的来源完全不参与搜索。

## 歌词条被隐藏

以下情况会自动隐藏:空闲宽度 < 80 DIP、任务栏自动隐藏开启、
前台应用全屏、完整菜单里手动隐藏。逐一检查后用"显示任务栏歌词"恢复。

## Explorer 重启后

任务栏几何会自动重新探测(最迟约 0.6 秒);托盘图标由系统重新放置。
若歌词条错位超过数秒,重启 LyricsX。

## 快捷键冲突

快捷键自定义页面在后续版本。当前版本默认注册 Ctrl+Alt+L 打开偏好设置,
被占用时应用启动日志(recorded W 级)可查。

## Spotify 连接失效

偏好设置 → 来源 → Spotify → 断开连接 → 重新连接。refresh token 过期或
被撤销时需要重新授权。断开后凭据管理器中的
`LyricsX/SpotifyRefreshToken` 会被删除。

## 查看与导出日志

日志位于 `%LOCALAPPDATA%\LyricsX\logs`(文件夹快捷方式在后续版本)。
日志不含歌名、艺术家、歌词内容、浏览器 URL 与凭据。

## 重置全部设置

退出 LyricsX → 删除 `%LOCALAPPDATA%\LyricsX\settings.json` → 重新启动。
(或卸载时选择删除用户数据。)

## 校验与签名

```powershell
Get-FileHash .\安装包 -Algorithm SHA256
Get-AuthenticodeSignature .\安装包 | Format-List Status, SignerCertificate
```

未签名包显示 NotSigned 属预期;自签名需先导入发布者提供的 .cer。
