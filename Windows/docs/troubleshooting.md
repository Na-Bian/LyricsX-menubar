# 故障排除

## 没有显示"正在播放"

1. 确认播放器正在播放;
2. 播放器需支持系统媒体控件(GSMTC):在播放器设置里启用"系统媒体传输控制/
   SMTC/媒体信息共享";
3. 偏好设置 → 播放器:确认未把来源固定到未运行的播放器(固定来源仅在
   该应用无会话时回退自动);
4. 重启播放器后再试。

## 找不到歌词 / 一直"正在搜索歌词…"

1. 右键歌词 → 手动搜索歌词…,或直接导入本地 LRC 文件;
2. 偏好设置 → 来源:确认目标来源已启用且排序靠前;
3. 偏好设置 → 过滤:关闭"严格匹配"可放宽搜索;
4. 部分曲目在所有来源均无同步歌词,属正常;
5. 网络受限时在线来源不可用,本地歌词文件不受影响。

## 歌词来源不对 / 优先级不生效

偏好设置 → 来源 → 上移/下移调整顺序。顺序在匹配质量相同时作为决胜依据。
禁用的来源完全不参与搜索。来源改动在下次启动 LyricsX 时生效。

## 歌词条被隐藏

以下情况会自动隐藏:空闲宽度 < 80 DIP、任务栏自动隐藏开启、
前台应用全屏、完整菜单里手动隐藏。逐一检查后用"显示任务栏歌词"恢复。

## Explorer 重启后

任务栏几何会自动重新探测(最迟约 0.6 秒);托盘图标由系统重新放置。
若歌词条错位超过数秒,重启 LyricsX。

## 快捷键冲突

偏好设置 → 快捷键:点击输入框后按下组合键捕获;被其他程序占用时应用会
提示"快捷键已被其他程序占用"。取消修改可恢复原注册。
默认注册 Ctrl+Alt+L 打开偏好设置;自定义绑定重启后由启动流程接管。

## Spotify 连接失效

偏好设置 → 来源 → Spotify → 断开连接 → 重新连接。refresh token 过期或
被撤销时需要重新授权。断开后凭据管理器中的
`LyricsX/SpotifyRefreshToken` 会被删除。

## 查看与导出日志

右键歌词 → 打开日志文件夹;日志位于 `%LOCALAPPDATA%\LyricsX\logs`。
日志不含歌名、艺术家、歌词内容、浏览器 URL 与凭据。

## 重置全部设置

退出 LyricsX → 删除 `%LOCALAPPDATA%\LyricsX\settings.json` → 重新启动。
(或卸载时选择删除用户数据。)

## 校验与签名

```powershell
Get-FileHash .\安装包 -Algorithm SHA256
Get-AuthenticodeSignature .\安装包 | Format-List Status, SignerCertificate
```

未签名包显示 NotSigned 属预期;自签名需先导入发布者提供的 .cer。
